Local Admin permissions are only justified at ACME when a user requires to download anything that will modify the machine directly. If you are simply a seasonal worker then you do not need admin permissions to access emails or write down documents.

Permissions should be escalated when you need to download such programs to make workflow faster. You *should not* simply give permissions when they ask for it. Always escalate and get permissions to do so first.

The evidence required is if the app is actually nessecary for your work. If you need to fill out a certain form in an app that requires admin permissions to be downloaded. But if this is simply a personal request that requires admin permissions then you should reconsider accepting their request because it is not required for a certain task.
