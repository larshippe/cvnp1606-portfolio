## Scenario:

A fake driver failure was put onto the machine through a .ps1 file provided by the instructor. Your task is to document everything about the driver error including the error codes, hardware IDs, details tab for identifying the exact device, driver date, driver version, driver provider, and if rollback is available or not.

You are then instructed to document the before state and then write a document including your findings, fix you will employ, why this fix specifically, and the expected outcome. You will then employ the fix and document a rollback plan if things stop working in the future.
