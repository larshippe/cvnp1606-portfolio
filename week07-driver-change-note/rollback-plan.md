## Rollback plan:

If your internet is no longer working or you have encountered other issues on your device follow these steps:

Win + X -> Device Manager -> Check for any error symbols -> Grey means enable, yellow means follow further instructions -> Right click on driver -> Update Driver -> Browse -> Let me pick from a list -> 12.19.1.32 -> If not present then follow steps below. 

If none of these options work for you, let windows update the drivers. 

If these don't work or you do not see symbols described in the guide above, bring your device, or if desktop computer a list of your problems, to the IT department to get it fixed.

Do not attempt the fix yourself unless specifically authorized by a member of the IT department.
