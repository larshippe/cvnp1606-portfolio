Scenario:

Machine has inflated CPU usage and I must document it and fix it.

Step 1: Document all resources using task manager, powershell commands, and resource monitor. 

Step 2: Find what program is using up the resources and decide what to do.

Step 3: Do ONE change to the device and document it and the outcome.

Step 4: Write after metrics if problem is solved and include screenshots of the three programs listed in Step 1. 

Step 5: Compare resources from before and after metrics.

What I did:

Within the scenario, a powershell command was run to increase CPU usage to very high amounts, slowing the machine down to a sluggish speed. I documented the before metrics - what the programs showed - before I even touched the machine. I then examined the resources and made a plan. I noticed the powershell programs within task manager and shut them down. I documented the change and provided a screenshot showing exactly that. I then wrote my after metrics and compared the before and after of the resources. I provided screenshots of the same programs I took screenshots of but showing after I fixed it. The machine sped right back up and was no longer sluggishly slow.
