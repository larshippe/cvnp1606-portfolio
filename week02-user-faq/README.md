## User Faq Question to answer

Q1: My screen doesn't look right, like it's too small.

Goal: Get User to the display settings to check resolution and use precise instructions to do so.

A1: Settings > System > Display > Display Resolution

## -----------------------------------------------

Q2: How do I change my mouse size? I can barely see it.

Goal: Direct the User to the pointer settings to change the size to their preferred size using precise instructions to do so.

A2: Settings > Accessibility > Mouse pointer and touch and then change the size of the mouse to your comfort.

## -----------------------------------------------

Q3: I can't see my printers when trying to print.

Goal: Guide the User to the printer section in the settings using precise instructions to troubleshoot the problem.

A3: Win + X > Device Manager > Printers. This will show if your printers are present.

## -----------------------------------------------

Q4: My computer is running slow, how can I see what is using all my resources?

Goal: Guide the User to the Task Manager to check for any processes that are obviously using lots of resources using precise instructions to do so.

A4: Ctrl + Shift + Esc, then sort by what resource is currently being used the most. If nothing is out of the ordinary, then provide things you have recently done or changed on the machine.

## -----------------------------------------------

Q5: There is a yellow triangle next to my sound icon on my taskbar. What do I do?

Goal: Guide the User to the device manager to check for driver updates using precise instructions to do so.

A5: Win + X > Device Manager > Audio inputs and outputs then Right-Click and update drivers.
